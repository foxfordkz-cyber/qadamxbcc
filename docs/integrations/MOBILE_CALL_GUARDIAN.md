# Qadam Shield 2.1 — звонок, семья и материалы по операции

В демонстрации используются учебные счета. Асия и её сын Арман — вымышленные персонажи. Клиент сам отмечает активный звонок. Приложение не слушает разговор и не запрашивает разрешения на микрофон или журнал вызовов.

## Что показать за 3–4 минуты

1. Перед выступлением подготовьте один учебный перевод на паузе, отметьте завершение разговора и дайте пройти пяти реальным минутам. Оставьте его квитанцию в истории. Включите семейный щит. Для демонстрации ответа контакта потребуется отдельно согласившийся тестовый участник и настроенный канал.
2. Войдите как клиент. Асию просят срочно перевести деньги. Откройте «Идёт звонок» либо сценарий «Социнженерия». Система принимает своё обычное решение. При защитной паузе виден спокойный экран «Перевод в обработке». Нажмите «Разговор закончился». Назовите клиенту время повторного вопроса.
3. На квитанции, подготовленной до выступления, откройте «Проверка после звонка». Ответьте «Меня торопили». Покажите независимый статус ответа доверенного лица. Включённый щит позволяет попросить одного согласившегося участника перезвонить по знакомому номеру. Статус очереди, подтверждённая доставка и ответ контакта различаются.
4. В Scam Check выберите синтетический скриншот сообщения. OCR работает на телефоне. Исправьте распознанный текст и нажмите «Проверить». Откройте хронологию в квитанции и сохраните проект заявления через системную печать Android. Через «Сообщить о мошенничестве» создайте обращение, затем покажите его с аккаунта SOC.

## Контракт мобильного шлюза

Базовый маршрут `/mobile/v1/protection`. Каждый запрос требует серверной сессии клиента. Шлюз проверяет владельца операции, ограничивает частоту запросов и возвращает `Cache-Control: no-store`.

| Метод | Маршрут | Результат |
| --- | --- | --- |
| GET / POST | /family | Текущее состояние или изменение с полем action = enable / disable. Отключение вступает в силу через 24 часа, повтор не продлевает срок. |
| GET | /{transaction_id}/check | Состояние беседы, время сервера, срок, ответ владельца, отдельный статус контакта. |
| POST | /{transaction_id}/end | Однократная фиксация окончания отмеченного клиентом звонка при Cooling-Off. |
| POST | /{transaction_id}/answer | Поле answer = my_choice / pressure. Доступно через пять минут. Повтор того же ответа идемпотентен. |
| POST | /{transaction_id}/notify | Запрос обратного звонка старейшему активному контакту с отдельным согласием. Для операции выбирается один получатель. |
| GET | /{transaction_id}/packet | Проекция сохранённых фактов операции, отчётов и ответа клиента. Android формирует PDF средствами системной печати. |

Подтверждение доверенного лица обозначает получение сообщения. Опрос клиента и этот ответ не дают права распоряжаться деньгами. Отзыв согласия участника всегда доступен сразу. Ограничение в 24 часа относится к настройке владельца. Просроченную паузу worker проверяет перед отправкой.

Миграция `0009_mobile_protection` добавляет две таблицы поверх объединённой истории `0008_core_integration_merge`. Порядок выпуска на тестовом стенде — миграция, шлюз новой версии, затем APK. Новые маршруты должны быть доступны на HTTPS-адресе, заданном при сборке. Сведения о звонке выводятся из первоначального контекста запроса. Для автоматического сигнала в банковском приложении потребовались бы согласованная с владельцем интеграция SDK, разрешения платформы и отдельная проверка приватности.

## Дизайн и источники

Для этого сценария у Qaqpan наиболее понятный приоритет на главной — семейное событие находится рядом с ближайшим действием. В «Тихом коде» интересен переход от спокойного интерфейса во время разговора к проверке после него. У ITU-HACKATHON использовано наблюдение о компактных быстрых действиях, у Shield 360 — о единообразных карточках. Это оценка удобства сценария. Иллюстрация Асии и Армана создана специально для Qadam. Светлая бумажная поверхность, тёмный хвойный цвет и тёплый акцент обозначают обычные и требующие внимания элементы. Цвет дополнен текстом.

- [Qaqpan](https://github.com/adiletpn/Qaqpan)
- [Тихий код](https://github.com/narutouciha431-sketch/tihiy-kod)
- [ITU-HACKATHON](https://github.com/ramazanabdimalik/ITU-HACKATHON)
- [BCC Shield 360](https://github.com/MaratelloMaJo/bcc-shield-360)
- [Qorgan](https://github.com/Ibrakazah/qorgan)

Пакет содержит Tesseract.js, Tesseract.js-core и языковые данные rus/kaz из зафиксированных NPM-пакетов. Снимки не передаются OCR-сервису. В Scam Check отправляется только текст, который клиент подтвердил.
