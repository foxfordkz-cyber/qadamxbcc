## Запуск кабинета

В android-app выполните `npm ci` и `npm run web`. Результат находится в backend/.qadam-web и содержит только клиентские ресурсы. Запустите обычный тестовый шлюз из backend с уже подготовленными настройками двух демоаккаунтов. Он подхватывает собранный каталог при запуске. Откройте /wallet/ на том же origin, что и /mobile/v1. Для командного демо требуется HTTPS. Локальный предпросмотр поддерживает loopback на 127.0.0.1. Для APK адрес задаётся demo-origin.txt или QADAM_API_ORIGIN при сборке. Браузеру доступна строго ограниченная ссылка /wallet/?operation=<uuid> или /wallet/?report=<uuid>. Права проверяются сервером при чтении записи. Пароли и токены никогда не помещаются в ссылку.

Для страницы установки скопируйте проверенный подписанный Qadam-Shield-2.5.apk в backend/.qadam-web/install/ и повторите `npm run web`. Ссылка появится только при наличии APK. GitHub Pages публикуется отдельным процессом владельца. У существующего статического демо своя история.

## Заимствованные принципы

- [«Чистый счёт»](https://github.com/ERA216/ITU-Hackathon) — судьба денег рядом с суммой. Использованы записи Qadam и действующие статусы core.
- [SafeSign](https://github.com/KItsunexdd/sudo-love-me-TIU) — одна заметная сумма и понятный следующий шаг. Подтверждение контакта остаётся совещательным.
- [NEXORA](https://github.com/SaginbekDaniel/SYNAPTIC-LABS) — граф и доказательства в контексте одного дела. Схема использует собственный модуль раскладки и данные NetworkX.
- [SafeTransfer](https://github.com/ramazanabdimalik/ITU-HACKATHON) — результат фонового запроса применяется только к текущей сессии и экрану.
- [BCC Shield 360](https://github.com/MaratelloMaJo/bcc-shield-360) — единые токены и отдельный режим показа для оператора.

Компоненты и графика созданы в проекте. Фотографии, торговые марки и исходный код конкурентов не переносились.

## Показ за 2 минуты 45 секунд

1. Войти клиентом в браузере и на Android. Отправить обычный учебный перевод на телефоне. На сайте открыть поступившую в историю операцию и сверить сумму и ID.
2. На сайте выбрать сценарий «Социнженерия». Открыть появившуюся проверку на телефоне. Показать срок, судьбу денег и состояние Guardian. При тестовой доставке обозначить её прямо.
3. Отменить учебный перевод клиентом. Сверить квитанции в двух каналах. Под учётной записью сотрудника открыть то же событие и связанное дело, исследовать получателя и операции в журнале.
4. Сценарий «Дроп-сеть» показывает жёсткую блокировку. Подозрение доверенного контакта само по себе не присваивает получателю статус мошенника.

## После обязательной приёмки

Стабильный домен и Android App Links принадлежат отдельному развёртыванию. Возврат входящего платежа и изменение финансовых полномочий Guardian требуют решения владельца core. Реальная доставка Telegram требует согласия владельца чата на конкретную действующую live-сессию.
