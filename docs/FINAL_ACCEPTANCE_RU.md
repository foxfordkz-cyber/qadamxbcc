# Приёмка Saq Bol 2.9

Дамир Карабек собрал проверки интегрированного релиза в PR #29. Бекзат подготовил сценарии для командной Android-сборки и сохранил исходные квитанции из учебного стенда. [Интегрированный релиз](https://github.com/foxfordkz-cyber/qadamxbcc/pull/29) · [Работа над командной сборкой](https://github.com/foxfordkz-cyber/qadamxbcc/pull/28)

| Что проверяем | Как воспроизвести | Что должно произойти |
| --- | --- | --- |
| Решения антифрода | Из `backend` запустить `uv run python -m scripts.payee_followup_replay` | На 12 парах примеров восемь мошеннических и один честный перевод получают паузу. Контрольные 120 операций сохраняют прежние баллы и решения. [Набор и ограничения](SCENARIO_STAND.md) |
| Рассмотрение дела | В комнате жюри «с историей» войти как сотрудник SOC, открыть дело и выбрать операцию из выписки получателя | В выписке видны направление, сумма до тиына и время исполнения. Открывается квитанция с тем же ID. Выписка ограничена восемью последними операциями за сутки до рассматриваемого перевода. [Доступы жюри](../README.md#jury) |
| Ответ клиенту | В одной комнате открыть клиентский и служебный кабинеты в разных профилях, оформить обращение по приостановленному переводу и закрыть дело в SOC | Клиент видит вывод сотрудника, исходную сумму и актуальный статус перевода. Удержание денег и закрытие обращения учитываются раздельно. |
| Семейная защита | В учебной комнате подключить доверенное лицо и открыть его приглашение в отдельном профиле | Ответ привязан к одной операции. Внешняя доставка Telegram требует отдельного подключения тестового чата. [Настройка Telegram](integrations/TELEGRAM_BOT_SETUP.md) |
| Обновление Android | Сверить пакет, SHA-256 и сертификат с манифестом своего канала. Открыть страницу с телефона или по QR | Сайт выдаёт подписанный APK 2.9. Для установки поверх старой версии нужно выбрать тот же канал. [Манифесты и инструкция](RELEASE_DISTRIBUTION_RU.md) |
| Восстановление | Из `backend` с запущенным Docker выполнить `uv run --frozen --python 3.12 python -m scripts.rehearse_release_storage` | Синтетические операции, сессии и журнал сохраняются после двух перезапусков API. Восстановленная копия PostgreSQL сверяется по записям и схеме. [Хранение данных](PERSISTENCE_AND_RECOVERY_RU.md) |

На локальной копии две роли проверили одно обращение на 900 000,25 ₸. После закрытия дела сотрудником клиент получил результат на казахском и русском. Сумма на счёте осталась прежней, сервер продолжал удерживать перевод. Отдельная проверка подтвердила, что клиенту закрыт доступ к выписке получателя из дела SOC.

Во второй комнате проверили семейную защиту через три раздельных сеанса. Клиент включил защиту и запросил перевод на 900 000,25 ₸. Доверенное лицо сверило реквизиты и сообщило о подозрении. При попытке завершить проверку сервер заблокировал перевод. Сотрудник закрыл связанное обращение, клиент получил квитанцию с тем же ID операции. Баланс до и после составил 4 785 900,00 ₸. Прогон использовал учебный канал доставки комнаты.

На прогретом локальном прогоне 180 обычных платежей получили одобрение. p95 скорера составил 2,78 мс, p95 запроса через ASGI и SQLite — 29,32 мс. В отдельном тесте на 500 операциях с fakeredis p95 ML составил 0,49 мс, p95 движка — 8,11 мс. Эти измерения относятся к синтетическим данным и локальному оборудованию.

Результаты Linux-сборки, изолированной проверки жюри и восстановления доступны в проверках выпуска. [Проверки 2.9](https://github.com/foxfordkz-cyber/qadamxbcc/pull/29/checks)
