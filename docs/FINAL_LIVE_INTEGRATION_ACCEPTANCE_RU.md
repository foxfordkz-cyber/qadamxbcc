## Подтверждённая инфраструктура

- Supabase `Shezhire/qadam-demo` принадлежит другому проекту — владелец подтвердил это в чате. Не использован, таблицы и настройки не менялись.
- Render `saq-bol-api-db`, PostgreSQL 18, Oregon, Free: существует; срок действия в панели — 20 декабря 2026. Это ограниченный учебный ресурс, не бессрочное production-хранилище.
- В этом экземпляре отдельно созданы `saq_bol_staging` и `saq_bol_staging_restore`, принадлежащие новому ограниченному SQL-пользователю. PUBLIC-доступ к новым базам отозван. У нового пользователя нет SELECT grants на таблицы `bcc_shield`. Данные существующей основной базы не изменялись.
- Внешний SQL-сеанс с ноутбука: TLS 1.3, проверка сертификата сервера. Полный Alembic upgrade на пустой `saq_bol_staging` дошёл до `0016_dispute_history`.
- Пользователь отдельно разрешил временное сетевое правило `/32` только для ноутбука. После backup/restore правило необходимо удалить. Полные URI/пароли сохранены локально с Windows DPAPI и персональным ACL, в репозиторий не попадают.
- Render `saq-bol-api-cache`: Valkey 8, Free, 25 MB, 50 connections, persistence off. Staging резервирует только логическую DB 12; перед первым seed обязателен отказ при её непустом состоянии. Финансовые события и очередь остаются в SQL. Сессии могут потребовать повторного входа после перезапуска самого Valkey.
- Старый `saq-bol-mobile` не обновлялся и не перезапускался. Сохранение новой базы не восстанавливает утраченную временную историю старой.

## Изменения для реального развёртывания

`staging-api` проверяет имя отдельной базы, отдельного пользователя, TLS и Redis DB 12. Первый bootstrap разрешается явно; существующие данные защищает прежний idempotent bootstrap. Миграции выполняет оператор до запуска, а не платный недоступный pre-deploy job.

Опциональный mobile hosted worker использует существующий SQL outbox. Fake-режим не создаёт Telegram Bot. Live-режим использует прежний PostgreSQL advisory-lock runner и запускается только с новым согласием. При завершении lifespan фоновые задачи останавливаются. По умолчанию этот режим выключен, старые сервисы не меняются.

В сборке staging отключена упаковка Android installer: build 24 указывает на старый API, новый candidate пока нельзя выдавать за принятый релиз. Дизайн Айданы и финансовый движок сохранены.
