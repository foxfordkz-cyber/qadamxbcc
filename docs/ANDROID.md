# Saq Bol × BCC · Android және веб-әмиян / Android и веб-кошелёк

**Қазақша.** Команда берген `client_demo` логині мен жеке сынақ құпиясөзін Android қолданбасына немесе браузердегі әмиянға енгізіңіз. Оқу аударымын жасап, түбіртектегі операция нөмірін сақтаңыз. Қызметкер өз `admin_demo` тіркелгісімен кіргенде дәл сол нөмір SOC тізімінде көрінеді. Екі құрылғы бір мобильді сынақ базасын пайдаланады. [Әмиянды ашу](https://saq-bol-mobile.onrender.com/wallet/)

**Русский.** Войдите под `client_demo` в APK или в браузере с тестовым паролем, полученным от команды. Выполните учебный перевод и сохраните номер квитанции. В другом профиле браузера войдите под `admin_demo` и найдите тот же номер в SOC. Обе роли читают один журнал мобильного стенда. [Открыть кошелёк](https://saq-bol-mobile.onrender.com/wallet/)

- **APK.** Установочный файл собирает GitHub Actions. Откройте успешный запуск для нужного коммита и скачайте артефакт APK. Android и браузер получают решения по переводам от одного сервера. [Сборки Android](https://github.com/foxfordkz-cyber/qadamxbcc/actions/workflows/android-apk.yml)
- **Данные.** Бесплатный мобильный стенд использует синтетические счета. После сна или перезапуска история начинается заново. Для демонстрации настоящей связки с тестовым Telegram-ботом используйте основной веб-стенд с его отдельной базой. [Основной стенд](https://saq-bol-bcc.zerdeliportald.workers.dev/mobile)
- **Локально.** Из корня проекта выполните `npm --prefix android-app ci`, затем `npm --prefix android-app run web`. Запустите `docker compose -f docker-compose.android.yml up -d --build` и откройте `http://127.0.0.1:18001/wallet/`. Способ подключения телефона, параметры сборки и получение паролей описаны в [инструкции Android](../android-app/README.md).
