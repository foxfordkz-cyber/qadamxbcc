# Сборка презентации Saq Bol

Единый источник текстов: `frontend/src/content/pitch.json`. Его используют экран
`/pitch` и две редактируемые презентации по восемь слайдов:
`deliverables/BCC-Shield-ru.pptx` и `deliverables/BCC-Shield-kk.pptx`.
`deliverables/pitch-manifest.json` связывает SHA-256 нормализованного исходного JSON
с SHA-256 обоих проверенных файлов, чтобы обнаружить устаревшую презентацию после
правки текстов. Поле `sourceHashEncoding` задаёт алгоритм: разобрать исходный текст
через `JSON.parse`, сериализовать результат через `JSON.stringify` без отступов и
вычислить SHA-256 полученной строки в UTF-8. Порядок ключей сохраняется. Внешнее
форматирование и окончания строк LF/CRLF не меняют этот хеш. Хеши PPTX вычисляются
по полным байтам файлов.
В заметках каждого слайда сохранены текст докладчика, границы утверждений и ссылки
на источники, если они есть в JSON. Схемы и текст остаются объектами PowerPoint.

Генератор использует публичный `@oai/artifact-tool` и штатный финализатор навыка
Presentations. В этой среде live Artifact Session недоступен, поэтому подготовлен
локальный PPTX. Закрытые протоколы или учётные данные приложения не используются.

Для воспроизведения нужны Node.js, Python и установленный runtime/skill
Presentations. Пути предоставляет `load_workspace_dependencies` в Codex.
Конкретные пути компьютера не записаны в исходники. Установите:

```text
ARTIFACT_TOOL_MODULE=<абсолютный путь к @oai/artifact-tool/dist/artifact_tool.mjs>
PRESENTATION_SKILL_DIR=<абсолютный путь к skills/presentations>
RUNTIME_PYTHON=<абсолютный путь к bundled python>
RUNTIME_NODE_MODULES=<абсолютный путь к bundled node_modules>
```

Если пакет доступен обычному импорту Node, `ARTIFACT_TOOL_MODULE` можно не
задавать. Шрифт по умолчанию — Segoe UI с казахской кириллицей. При другой среде
задайте `PITCH_FONT` доступным шрифтом с нужным набором символов и проверьте рендер.

Из корня репозитория запустите установленным Node.js:

```sh
node scripts/build-pitch.mjs
```

Генератор сначала экспортирует отдельный черновик, рендерит каждый слайд и
проверяет структуру, геометрию, размер 1280×720, шрифты, восемь слайдов и обратный
импорт Artifact Tool. Только прошедший финализатор файл попадает в `deliverables/`.
PNG, layout JSON и отчёты проверки остаются в игнорируемом
`.local-checks/pitch/<timestamp>/`. Повторная сборка заменяет только два конечных
PPTX после успешной проверки каждого языка.

После изменения текстов просмотрите все 16 PNG при полном размере: программные
проверки не заменяют проверку переносов, читаемости и точности утверждений.
Перед выступлением также откройте PPTX в используемой версии PowerPoint или
совместимом просмотрщике, поскольку этот генератор проверяет файл и локальный
рендер, а не поведение каждого офисного приложения.
