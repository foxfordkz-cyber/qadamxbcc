# Показ за три минуты

| Время | Действие | Что показать |
|---|---|---|
| 0:00–0:30 | На Honor открыть установленный командный APK 2.9 и войти как client_demo. Для гостей открыть QR с [публичной страницы Android](https://saq-bol-bcc.zerdeliportald.workers.dev/download/android/). | Баланс и учебная маркировка. |
| 0:30–1:10 | В изолированном демо выбрать учебного получателя сценария социальной инженерии. Отметить просьбу о переводе по телефону. | Сумма, получатель, причина паузы, деньги на счёте и срок по серверу в одной квитанции. |
| 1:10–1:40 | Открыть Guardian по этому переводу. | Степень согласия и доступный статус уведомления. Назвать используемый адаптер. Для live показа требуется согласованный тестовый чат. |
| 1:40–2:30 | Под admin_demo открыть связанное обращение и исходную операцию. | Какие факты усилили и ослабили подозрение, чего ещё нет в данных. Отправить разрешённый ответ через существующее дело. |
| 2:30–3:00 | Вернуться в клиентский кабинет. | Та же сумма и ID, ответ SOC и доступный клиенту пакет инцидента. |

Для всего сценария с изменением данных используйте один изолированный стенд с синтетическими счетами и его клиентский и служебный кабинеты. Переданный APK на Honor подключён к публичному Render. Для локального показа начать с APK на телефоне можно чтением ранее существующей квитанции, затем открыть оба кабинета изолированного стенда в браузере. Это две разные базы. Запасные примеры — обычный перевод 25 000 ₸ и заблокированный перевод на учебный дроп-хаб. Показ временного удержания и итогового списания ведётся по состоянию на сервере. Пароли доступны вне репозитория.
