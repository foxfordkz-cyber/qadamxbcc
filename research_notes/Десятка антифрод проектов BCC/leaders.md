# Шесть проектов защиты переводов

## У кого сильнее сценарий клиента и работа сотрудника?

### Вывод

На 20 ноября 2026 сравнивались проекты, единица наблюдения — репозиторий, а не команда. Для шести проектов получены HEAD основной ветки main через `git ls-remote --symref`, деревья файлов через GitHub API и содержимое ключевых исходников с привязкой к SHA. Чужие сервисы и тесты не запускались.

### Факты

- **«Тихий код»** учитывает незавершённое удержание отправителя в следующей попытке на другого получателя. В панели сотрудника есть серверные обработчики для решения по переводу, подтверждения и снятия метки с получателя, журнала и выгрузки сведений. UX подтверждается двумя отдельными интерфейсами для клиента и сотрудника. Решение принимает набор правил. В журнале SQLite один SQL-вызов фиксируется отдельным коммитом, поэтому целостность многошагового изменения баланса заслуживает отдельной проверки. [Детектор](https://github.com/narutouciha431-sketch/tihiy-kod/blob/82b9cbfa4ddae759d72981942beab11c865b42cd/server/risk.py#L25) · [API сотрудника](https://github.com/narutouciha431-sketch/tihiy-kod/blob/82b9cbfa4ddae759d72981942beab11c865b42cd/server/main.py#L507) · [экраны](https://github.com/narutouciha431-sketch/tihiy-kod/tree/82b9cbfa4ddae759d72981942beab11c865b42cd/web) · [работа с SQLite](https://github.com/narutouciha431-sketch/tihiy-kod/blob/82b9cbfa4ddae759d72981942beab11c865b42cd/server/db.py#L15).
- **Qaqpan** объясняет риск родственнику через сумму, долю баланса и признаки звонка. В тестах семейное ожидание завершается эскалацией по таймауту. В правилах выделен перевод на собственный счёт в другом банке во время звонка. Для показа есть три телефона на одном проекторе, пульт ведущего и отдельный полноэкранный маршрут для телефона. Сервер хранит состояние в памяти одного процесса. Сценическая панель ведущего сама по себе не доказывает наличие полноценного рабочего места расследований. [Семейное решение](https://github.com/adiletpn/Qaqpan/blob/5fa87067bf89eed5bcff770b3587370af506d57c/api/family.py) · [правила](https://github.com/adiletpn/Qaqpan/blob/5fa87067bf89eed5bcff770b3587370af506d57c/api/risk.py) · [маршруты интерфейса](https://github.com/adiletpn/Qaqpan/blob/5fa87067bf89eed5bcff770b3587370af506d57c/README.md#L30) · [ограничение архитектуры](https://github.com/adiletpn/Qaqpan/blob/5fa87067bf89eed5bcff770b3587370af506d57c/README.md#L75).
- **TransferGuard** проводит пользователя через проверку до подтверждения перевода. При незаполненных ответах выдаёт отдельное действие запроса контекста, при высоком риске предлагает остановиться и свериться с банком. Сервер валидирует запрос, React-страница ожидает ответ. В закреплённом дереве присутствуют пять правил и тесты, а серверный журнал перевода и рабочее место сотрудника отсутствуют. [Решения и оценка](https://github.com/your-golden-hour/transferguard-itu/blob/c8da1f67eafc9de0cf8067a08139bd5b72c98092/lib/risk.ts) · [экран клиента](https://github.com/your-golden-hour/transferguard-itu/blob/c8da1f67eafc9de0cf8067a08139bd5b72c98092/app/page.tsx#L43) · [дерево исходников](https://github.com/your-golden-hour/transferguard-itu/tree/c8da1f67eafc9de0cf8067a08139bd5b72c98092).
- **DropRadar** специализируется на аналитике дропперов. Сотрудник меняет параметры потока и получает новый результат от встроенного ансамбля деревьев. В режиме воспроизведения событий отображаются заранее записанные оценки. В SOC есть действия с подозрительным счётом, которые меняют состояние браузера. На проверенном коммите всё дерево — один файл с именем `index.html.`. В нём нет воспроизводимого конвейера обучения. [Алгоритм в браузере](https://github.com/aikenmurat1-design/dropradar/blob/1bc435ad050d7f7d05ce3e49f1bba8b7e2230fb6/index.html.#L289) · [интерактивная песочница](https://github.com/aikenmurat1-design/dropradar/blob/1bc435ad050d7f7d05ce3e49f1bba8b7e2230fb6/index.html.#L439) · [воспроизведение](https://github.com/aikenmurat1-design/dropradar/blob/1bc435ad050d7f7d05ce3e49f1bba8b7e2230fb6/index.html.#L348) · [операторские действия](https://github.com/aikenmurat1-design/dropradar/blob/1bc435ad050d7f7d05ce3e49f1bba8b7e2230fb6/index.html.#L544).
- **BCC Аман** показывает приостановку и консультацию с близким в связанных клиентском, семейном и банковском экранах. Локальные правила оценивают сумму, контекст, множество отправителей и дальнейший вывод. Реализация суммирует историю сессии; окно в 24 часа, упоминаемое в интерфейсе, в этом расчёте не фильтруется по времени. Имитация проверки лица завершается таймером. [Описание экранов](https://github.com/aikenmurat1-design/bcc-aman/blob/ed4ca472e8efc5c57af06d3f906f5dcfafa83537/README.md) · [клиентский журнал и правила](https://github.com/aikenmurat1-design/bcc-aman/blob/ed4ca472e8efc5c57af06d3f906f5dcfafa83537/index.html#L184) · [приостановка и согласие](https://github.com/aikenmurat1-design/bcc-aman/blob/ed4ca472e8efc5c57af06d3f906f5dcfafa83537/index.html#L217).
- **Qorgan, aikenmurat1-design** публикует план показа перевода под диктовку. Файл `index.html` содержит текст в разметке Markdown. На этом коммите дерево состоит только из него; работающую модель, форму или API проверить по версии нельзя. Для DropRadar, BCC Аман и Qorgan установлен общий GitHub-автор, состав команд не установлен. [Сценарий](https://github.com/aikenmurat1-design/Qorgan/blob/77a8c0847e3b80aafdb82bda40970ecebd9bd71f/index.html) · [полное дерево](https://github.com/aikenmurat1-design/Qorgan/tree/77a8c0847e3b80aafdb82bda40970ecebd9bd71f).

## Чем подкреплены оценки?

### Факты

- У «Тихого кода» 85 синтетических сценариев. Авторы фиксируют 39 остановленных из 45 мошеннических и 5 задержанных из 40 честных. Код стенда и анализ чувствительности опубликованы. [Отчёт](https://github.com/narutouciha431-sketch/tihiy-kod/blob/82b9cbfa4ddae759d72981942beab11c865b42cd/docs/test-stand-results.md) · [стенд](https://github.com/narutouciha431-sketch/tihiy-kod/blob/82b9cbfa4ddae759d72981942beab11c865b42cd/scripts/test_stand.py).
- Qaqpan публикует тесты обычного перевода, семейной эскалации, разговора с настоящим банком и контекстного сигнала. Приведённые отдельно 47 примеров в METRICS оценивают классификацию сообщений; авторы отмечают влияние настройки на этом наборе. [Тесты](https://github.com/adiletpn/Qaqpan/blob/5fa87067bf89eed5bcff770b3587370af506d57c/tests/test_golden_path.py) · [метрики](https://github.com/adiletpn/Qaqpan/blob/5fa87067bf89eed5bcff770b3587370af506d57c/docs/METRICS.md).
- У TransferGuard опубликованы проверки правил и Playwright-сценарий. У DropRadar и BCC Аман можно проверить логику интерфейса, но отдельного тестового или обучающего стенда в этих деревьях нет. [Тесты TransferGuard](https://github.com/your-golden-hour/transferguard-itu/blob/c8da1f67eafc9de0cf8067a08139bd5b72c98092/tests/risk.test.ts) · [Playwright](https://github.com/your-golden-hour/transferguard-itu/blob/c8da1f67eafc9de0cf8067a08139bd5b72c98092/e2e/demo.spec.ts) · [DropRadar](https://github.com/aikenmurat1-design/dropradar/tree/1bc435ad050d7f7d05ce3e49f1bba8b7e2230fb6) · [BCC Аман](https://github.com/aikenmurat1-design/bcc-aman/tree/ed4ca472e8efc5c57af06d3f906f5dcfafa83537).

### Экспертные оценки для сведения

Последовательность чисел — защита клиента / детекция и доказательства движения средств / работа SOC / воспроизводимость. Шкала 0–3. «Тихий код» 3/2/3/3 = 11. Qaqpan 3/2/1/3 = 9. TransferGuard 2/2/0/2 = 6. DropRadar 0/2/2/1 = 5. BCC Аман 2/1/1/1 = 5. Qorgan от aikenmurat1-design 0/0/0/0 = 0, если считать только исполняемый продукт. Для UX можно выделить Qaqpan за проектор и связанные роли, DropRadar за изменяемый аналитиком эксперимент, TransferGuard за экран уточнения контекста. Эта оценка описывает пригодность сценария для показа по просмотренным UI-компонентам.

### Пробелы проверки

Не проводился пользовательский тест дизайна и единый слепой тест на размеченной выборке переводов банка. Успешный запуск всех чужих тестов и состояние публичных деплоев не проверялись. Внутренние проценты нельзя использовать для сравнения банковской эффективности.
