# Qadam Shield для Android

Приложение ставится на Android 7 и новее. На первом экране выберите язык, затем клиентский вход или SOC. Для показа без сервера есть автономный клиент с тремя примерами и просмотр обезличенного снимка SOC. Снимок содержит сохранённые оценки модели и статистику графа из синтетического прогона.

## Установка и вход

1. В GitHub Actions откройте успешный запуск **Android APK** для нужной ветки и скачайте артефакт `Qadam-Shield-android-apk`. Распакуйте APK и установите на тестовый телефон. Пакет `kz.qadamx.bccshield.demo` устанавливается рядом с исходным приложением Айданы.
2. Для режима с сервером из корня репозитория выполните `docker compose -f docker-compose.android.yml up -d --build --wait`. При первом запуске стенд создаёт отдельные PostgreSQL и Redis, применяет миграции и наполняет пустую базу синтетическими данными. Команда повторного запуска сохраняет историю. Запуск через USB использует только порт ноутбука `127.0.0.1:18001`.
3. На своём Android подтвердите USB-отладку для ноутбука и выполните `adb reverse tcp:18001 tcp:18001`. В приложении выберите роль и укажите `127.0.0.1:18001`. В эмуляторе подойдёт `10.0.2.2:18001` без USB-команды. Для подключения по Wi-Fi настройте доверенный HTTPS на частном IP и используйте его HTTPS-адрес.
4. Владелец стенда локально открывает `.local-checks/mobile-access/access.json`. Поле `client` даёт клиентский доступ, `admin` даёт операторский. Передавайте отдельно только код нужной роли. Это временные коды тестового сервера. Сессия по умолчанию действует 30 минут. Сам токен приложение держит в памяти. Остановить стенд можно командой `docker compose -f docker-compose.android.yml stop`.

## Что показать жюри

- **Клиент.** Выберите обычный перевод, затем социальную инженерию и подозрительную сеть. Сумму можно менять. Подтвердите параметры и откройте квитанцию. Сервер оценивает частоту, признаки звонка, сумму и связи получателя. Итог зависит от актуальной истории и существующих порогов. Пресеты используют только тестовых получателей.
- **Cooling-Off.** При удержании приложение показывает срок сервера. Ответьте на пять вопросов. При чистых ответах до истечения срока сервер сохраняет паузу. После истечения срока откройте квитанцию и подтвердите ответы повторно для решения ядра. Клиент может отменить удержание. При неопределённом исходе отправки доступна проверка сохранённого запроса и его безопасное закрытие.
- **SOC.** Войдите отдельно операторским кодом. В общей ленте работают фильтры, поиск и страницы. В карточке доступны причины решения, версия модели и вклады признаков, граф получателя и Incident Timeline. Пометка *suspected mule* означает повод для проверки. Синтетические обращения клиента доступны оператору, который может подтвердить обращение, открыть дело и изменить его состояние.
- **Защита.** Клиент может проверить синтетическое сообщение через Scam Check, сверить тестовый журнал звонков, посмотреть контакты, создать тестовое приглашение, отозвать согласие или проверить идентификатор в Mock Gateway. Диагностика SOC показывает состояния БД, Redis, интеграций и очереди. Для этой сборки используется fake Telegram. QR-экран Айданы открывает командный веб-клиент отдельно.

## Разработка

Android-основу и QR-подключение создала Айдана. Новый интерфейс RU/KK и шлюз ролей развивают этот модуль. ML, граф и транзакционные решения выполняет существующее ядро команды. Шлюз запускается отдельным процессом. Собственные маршруты ядра на порту мобильного шлюза не смонтированы. Ключи сервисов остаются на сервере.

Из `android-app` установите зависимости через `npm ci`, выполните `npm test`, `npm run test:ui`, `npm run sync`. Затем запустите `gradlew.bat assembleDebug` из `android-app/android` на Windows или `./gradlew assembleDebug` на Linux. Для сборки нужны JDK 21, SDK 36 и Node 22+. Подписанный отладочным ключом APK появится в `android/app/build/outputs/apk/debug/app-debug.apk` относительно каталога `android-app`.

GitHub Pages продолжает служить публичным статическим показом. Для обеих авторизованных ролей требуется тестовый шлюз. Стенд предназначен для синтетического хакатонного демо. Для промышленной эксплуатации потребуется банковская IAM и отдельная приёмка.
