# Saq Bol × BCC · Android

Android 2.9 нұсқасын бұрын қолданған арнадан жаңартыңыз. Сайт пен командалық қосымшаның қолтаңбалары бөлек. [Орнату нұсқаулығы](../docs/ANDROID.md)

Для обновления Android 2.9 выберите тот же канал, что при первой установке. Команда `assembleWebsite` собирает приложение сайта (`.website`), а `assembleShowcase` собирает командное приложение (`.demo`). Обе сборки подключены к мобильному HTTPS-серверу. Порядок сборки, проверки подписи и публикации описан в [инструкции выпуска](../docs/RELEASE_DISTRIBUTION_RU.md).

## Қазақша

Клиент аударым жасайды, тәуекел себептерін көреді және операцияны тоқтата алады. SOC қызметкері тиісті аударымды, графты және өтініштің тарихын ашады. Күмәнді скриншоттың мәтіні телефонда танылады. Әр оқу рөліне сервер жеке, мерзімі шектеулі сеанс береді.

Жергілікті іске қосу үшін төмендегі пәрмендерді орындаңыз. Браузерден http://127.0.0.1:18001/wallet/ мекенжайын ашыңыз. Қорғалған жергілікті файлда клиенттің (`client_demo`) құпиясөзі `client` өрісінде, SOC қызметкерінікі (`admin_demo`) `admin` өрісінде, платформа әкімшісінікі (`platform_demo`) `platform_admin` өрісінде сақталады. Әкімші техникалық көрсеткіштерді көреді және қызметкердің кіру рұқсатын басқарады. Бастапқы оқу қалдығы 5 000 000 ₸. Сома орындалған синтетикалық аударымдарға қарай өзгереді. Офлайн шолу бөлек үлгі деректерін пайдаланады.

## Запуск на ноутбуке

От корня репозитория запустите мобильный шлюз с отдельными PostgreSQL и Redis.

```sh
cd android-app
npm ci
npm run web
cd ..
docker compose -f docker-compose.android.yml up -d --build --wait
```

Откройте [кошелёк на localhost](http://127.0.0.1:18001/wallet/) и выберите ҚАЗ или РУС. Пароли находятся в локальном файле `.local-checks/mobile-access/access.json`. Клиенту `client_demo` соответствует поле `client`, сотруднику SOC `admin_demo` — `admin`, администратору платформы `platform_demo` — `platform_admin`. Локальный шлюз создаёт access.json только при его отсутствии и сохраняет пароли при повторном запуске. Повреждённый или неполный файл останавливает запуск без перезаписи. Этот файл не содержит пароли публичного Render. Для сценария CI с отдельными кодами можно установить `QADAM_MOBILE_AUTH_MODE=rehearsal` перед запуском Compose.

1. Войдите в аккаунт клиента. Откройте кошелёк, выберите учебного получателя, отправьте перевод и посмотрите серверную квитанцию. Учебный баланс рассчитывается от начальных 5 000 000 ₸ с учётом исполненных операций.
2. Откройте удержанный перевод с активным звонком, отметьте окончание разговора. Сообщение об обмане отменяет его через платёжное ядро. Через пять минут можно подтвердить собственный выбор. Платёжная пауза проверяется отдельно при решении о переводе.
3. Создайте обращение, запомните номер, выйдите из аккаунта и войдите как `admin_demo`. Откройте то же обращение, связанный перевод и граф.
4. Для веб-версии с приватным Telegram-входом на первом экране есть кнопка «Открыть веб-клиент». Локальный мобильный Compose использует тестовую доставку. «Офлайн-обзор» открывает автономные примеры.

Квитанции и дела обновляются между Android и браузером. [Проверка общего журнала и ссылка на веб-кошелёк](../docs/integrations/CONNECTED_WALLET_25.md). Для просмотра интерфейса APK в браузере можно отдельно выполнить `npm run preview` в `android-app/` и открыть порт 4173.

## APK и подключение телефона

**Бесплатный мобильный стенд.** Адрес для сборки командного APK — `https://saq-bol-mobile.onrender.com`. В [отдельном профиле Render](../deploy/render-mobile-free.yaml) работает один сервис Free с SQLite и приватным Redis. При запуске он создаёт новый набор синтетических данных. После сна или перезапуска история и сессии сбрасываются. Операция клиента появляется в SOC того же мобильного стенда. Веб-демо использует свою базу и своего Telegram-бота. В мобильном профиле доставка в Telegram имитируется. [Статус мобильного шлюза](https://saq-bol-mobile.onrender.com/health)

**Тегін мобильді стенд.** Клиенттің аударымы осы мобильді стендтің SOC панелінде көрінеді. Веб-демо бөлек дерекқорды пайдаланады. Тегін сервер ұйқы режимінен шыққанда немесе қайта қосылғанда сессиялар мен аударымдар тарихы жаңадан басталады. Telegram хабарламалары осы стендте имитацияланады.

С версии 2.5 тот же кошелёк можно открыть в браузере с учебной учётной записью мобильного стенда. Для входа используются защищённые cookie. [Открыть кошелёк / Әмиянды ашу](https://saq-bol-mobile.onrender.com/wallet/)

Для своего экземпляра разверните этот профиль из приватного репозитория в Render. Укажите приватный каталог в `QADAM_PRIVATE_DIR` и выполните `python -m scripts.mobile_accounts` из `backend/`. Скрипт создаёт недостающие файлы учётных записей. Передайте scrypt-хэши отдельных паролей в `BCC_MOBILE_CLIENT_HASH`, `BCC_MOBILE_ADMIN_HASH` и, для входа администратора платформы, `BCC_MOBILE_PLATFORM_HASH`. Сборке APK нужен публичный HTTPS-адрес из поля URL созданного сервиса в переменной `QADAM_API_ORIGIN`.

Нужны JDK 21+, Android SDK 36 и Node.js 22+. Для работы через USB в Windows PowerShell выполните из `android-app` при запущенном локальном шлюзе.

```powershell
$env:QADAM_USB_REHEARSAL = "1"
adb reverse tcp:18001 tcp:18001
npm run sync
Push-Location android
.\gradlew.bat --no-daemon --max-workers=2 assembleDebug
Pop-Location
adb install -r android/app/build/outputs/apk/debug/app-debug.apk
```

Сборка для разработки использует пакет `kz.qadamx.bccshield.dev` и по умолчанию подключается к командному мобильному стенду. Для своего экземпляра задайте `QADAM_API_ORIGIN` до сборки APK. В CI можно использовать одноимённую GitHub Actions variable. В режиме USB-репетиции debug-сборка с `QADAM_USB_REHEARSAL=1` использует локальный шлюз.

## Отдельный HTTPS-стенд

Запустите контейнер из `backend/Dockerfile` командой `python -m scripts.mobile_hosted` с рабочим каталогом `backend`. Этот процесс обслуживает `/mobile/v1` и `/health`. Используйте отдельные учебные PostgreSQL и Redis и задайте на сервере:

- `BCC_ENVIRONMENT=demo`, `BCC_BOOTSTRAP_DEMO=true`, `BCC_MOBILE_ENABLED=true`, `BCC_MOBILE_AUTH_MODE=password`.
- `BCC_DATABASE_URL`, `BCC_REDIS_URL` и разные scrypt-хеши в `BCC_MOBILE_CLIENT_HASH` и `BCC_MOBILE_ADMIN_HASH`. Для отдельного кабинета администратора задайте также `BCC_MOBILE_PLATFORM_HASH`. Личные пароли создаёт `QADAM_PRIVATE_DIR=<private-dir> python -m scripts.mobile_accounts`. Функция `app.mobile_gateway.passwords.encode` получает серверный хеш каждого пароля.
- Для учебной доставки `BCC_INTEGRATIONS_ENABLED=true`, `BCC_INTEGRATIONS_ENVIRONMENT=test`, `BCC_INTEGRATIONS_TELEGRAM_MODE=fake` и отдельный `BCC_INTEGRATIONS_SIGNING_KEY`. Приватный Telegram-круг веб-стенда имеет собственные базу и проверку владельца.

## Проверки

```sh
npm test
npm run test:ui
npm run sync
```

Сквозной сценарий Android в GitHub Actions запускает PostgreSQL/Redis, отправляет учебный перевод через скоринг и открывает дело в SOC. Приёмка конкретного телефона и версии APK фиксируется отдельно.
