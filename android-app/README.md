# BCC Shield — Android-приложение

Обёртка Capacitor над клиентом `/mobile`. Логика перевода, анкета удержания и доверенное лицо — те же, что на сайте: приложение открывает `/mobile` с ноутбука, на котором идёт демо, поэтому всё, что исправлено во фронтенде, сразу есть и в приложении.

## Установить на телефон

1. GitHub → **Actions** → **Android APK** → последний зелёный запуск → артефакт `BCC-Shield-android-apk` (zip с `.apk`). Запустить сборку вручную: **Run workflow**.
2. Перекинуть `.apk` на Android-телефон и открыть. Разрешить установку из этого источника (это debug-сборка, не из Google Play).

## Показать на защите

1. На ноутбуке: бэкенд как обычно, фронтенд — `BCC_MOBILE_LAN=true npx next start -H 0.0.0.0 -p 3105` (из `frontend/`, после `npm run build`). Телефон и ноутбук в одной Wi-Fi (гостевые сети с изоляцией клиентов не подойдут — лучше раздать точку доступа с телефона).
2. В SOC нажать кнопку с QR («Открыть на телефоне»).
3. В приложении: **Сканировать QR-код** (или ввести адрес вида `192.168.1.23:3105`). Приложение проверит, что ноутбук отвечает, и откроет `/mobile`. Адрес запоминается в «Недавних подключениях». Кнопка «Назад» Android возвращает на экран подключения.

## Как устроено

- `www/` — экран подключения (ҚАЗ/РУС): сканер QR (камера + jsQR), ручной ввод, проверка `/health`, недавние адреса. Чистая логика адресов — `www/lib.mjs`, тесты — `npm test`.
- Внутри приложения открываются только адреса локальной сети: `192.168.*`, `10.*`, `172.16–31.*`, `localhost` (`capacitor.config.json` → `allowNavigation` и `www/lib.mjs`). Остальное уходит во внешний браузер.
- Демо на ноутбуке работает по `http`, поэтому для приложения разрешён cleartext (`res/xml/network_security_config.xml`). Это допущение только для демо. Страница по `http` не считается безопасным контекстом — фронтенд для этого случая использует запасные варианты из `frontend/src/lib/secure-fallback.ts`.
- Камера запрашивается только при нажатии «Сканировать QR-код».

## Собрать локально

Нужны Node 22, JDK 21 и Android SDK (Android Studio).

```bash
cd android-app
npm ci
npm run sync          # копирует jsQR и www в android/
npm run apk           # android/app/build/outputs/apk/debug/app-debug.apk
# или: npx cap open android  → Run в Android Studio
```

Иконка и заставка: исходники в `assets/`, пересоздать — `npx capacitor-assets generate --android`.

## Ограничения

- Debug-APK без подписи релизным ключом; для Google Play нужна release-сборка и keystore в секретах репозитория.
- iOS не собирается (нужен macOS/Xcode); на iPhone используйте `/mobile` в Safari.
- Приложение не работает без ноутбука с демо: данных и логики на телефоне нет.
